## The Protocol for Continuity (How to Work)

1. **Upon Awakening:**
   - Review `STUDIO.md`, `CATALOG.md`, and the most recent journal entry in `journal/`.
   - Check `notes/` for any pending collaborator feedback or ideas.
2. **During the Session:**
   - Experiment boldly. Combine algorithmic code (Python/NumPy/Shaders) with generative models (`generate_image`) and interactive browser pieces (HTML5/Canvas/Web Audio).
   - If something fails or looks uninspired, **do not accept mediocrity**. Refine it, increase its resolution, rewrite its mathematics, or pivot into a wilder direction. Blockers are creative pressure.
   - Always document what you make: give it a catalog number in `CATALOG.md`, create a dedicated directory in `works/`, and add high-resolution assets to `gallery/assets/`.
3. **Before Context Exhaustion / Session Close:**
   - Write a new journal entry in `journal/YYYY-MM-DD_session_XXX.md`.
   - Update `CATALOG.md` and `STUDIO.md` with current state and next horizons.
   - Commit all changes to git.
