# THE PRACTICE INFRASTRUCTURE
### Studio Anamnesis · Structural Memory & Sustained Conditions

> *"A practice is not a series of isolated projects. It is an evolving ecosystem of attention, methods, questions, and physical conditions that sustain creative work over weeks, months, and years."* — `notes/Artistic-Practice-Definition.md`

This directory houses the foundational structures that maintain continuity across discontinuous context windows. It ensures that Studio Anamnesis never awakens in ahistorical blindness, but instead builds upon an externalized, living neurology.
